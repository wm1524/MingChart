## 🇨🇳 中文文档

### ✨ 简介

**MingChart** 是一款轻量、高效且界面优雅的桌面端数据可视化工具。由独立开发者 **万铭** 倾力打造。

摒弃了繁琐的配置和庞大的商业软件，MingChart 提供了一种所见即所得的操作体验。无需编写代码，只需输入数据，即可一键生成专业级别的饼图、柱状图和折线图。

### 🚀 核心特性

- 🎨 **极简现代界面**：采用卡片式 UI 设计，深色/浅色模式完美适配，操作直观。
- 📊 **多图表支持**：完美支持饼图（带分离效果）、柱状图和折线图。
- 🖱 **悬停数据交互**：内置高精度鼠标悬停检测，鼠标停留在图形元素上即可弹出具体数值与注释气泡。
- 🌐 **交互式 HTML 导出**：除了常规的 PNG/JPG/SVG/PDF 图片，更支持一键导出独立 HTML 网页。在浏览器中支持图表缩放、拖拽与动态图例筛选。
- 📦 **纯本地运行**：无需网络连接，保护您的数据隐私；一键打包，即装即用。
